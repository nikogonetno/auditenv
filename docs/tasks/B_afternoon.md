- Тест. Минимальная политика из README раздела 4, сохранённая в файл, проходит эпизод `tests/fixtures/mini_v03` через `--policy-cmd` и получает ту же награду, что через Python API. Тест в Docker-шаге CI под пользователем `auditpolicy`.

4. **Период только 2026 год.** `2027-01` и `2025-12` дают ValueError.
5. **C1 только в марте, июне, сентябре и ноябре.** `2026-05` даёт ValueError со списком месяцев. На 20 seed с `period: null` выпали 03, 06, 09 и 11. Сдвиг только `+00:00` даёт ValueError.

7. **Маленькие книги.** 20 документов дают 40–42 строки, 30 документов 62–69 (по 20 seed).

Задевает проверку скрытого набора вне Docker, которую жюри может сделать перед закрытым прогоном | блок L17 ниже → живой `python3 -c import time; time.sleep(45)`, папка `auditenv-policy-…/work` и ненулевое число `truth.json` (у меня 5) |
| L18 | низкая | **Путь журнала в несуществующей папке даёт трассировку Python.** Остальные ошибки CLI дают одну строку и код 2. Здесь `FileNotFoundError` с трассировкой и код 1. Эпизоды при этом не идут и ничего не пишется | `python3 -m auditenv.run --policy oracle --config configs/dev_v2.json --seed 2000 --trajectories /nonexistent/t.jsonl; echo "exit $?"` → трассировка, `exit 1` |

Блок L17, из корня репозитория:

```bash
mkdir -p out/qa_tmp out/qa_tmp2
TMPDIR=$PWD/out/qa_tmp python3 -m auditenv.run --policy-cmd "python3 -c 'import time; time.sleep(45)'" --config configs/dev_v2.json --mode train --sandbox off --time-limit 30 > /dev/null 2>&1 &
sleep 8; kill -TERM $!; sleep 1; pgrep -fa 'sleep[(]45'; find out/qa_tmp -mindepth 1 -maxdepth 2
python3 -c 'import json; json.dump({"version": "qa", "episodes": [{"seed": 3000 + i, "config": {}} for i in range(40)]}, open("out/qa_forty.json", "w"))'
TMPDIR=$PWD/out/qa_tmp2 timeout -s TERM 2 python3 -m auditenv.run --policy oracle --config out/qa_forty.json --mode train --sandbox off > /dev/null; find out/qa_tmp2 -name truth.json | wc -l
```

**Что жюри заметит первым после правок.**

1. **Прогон больше не ломается снаружи.** На 226 запусках, включая сигналы в случайный момент и конец места на диске, нет ни одной трассировки. Журналы всегда кончаются целыми строками и согласованы между собой.
2. **Любая остановка чистая.** Ctrl-C, SIGTERM, SIGHUP, SIGQUIT и ушедший читатель stdout убирают за собой всё. Они печатают не больше одной строки и выходят с кодом 128 + номер сигнала.
3. **Остались только названные пределы.** `kill -9`, внук через `setsid` вне Docker и FIFO README называет сам. `docker stop` по-прежнему проверяется только юнит-тестами.
